# Projet BAS

## 📌 Description

**Projet BAS** est un site web réalisé dans le cadre de mon apprentissage en développement d'applications.

L'objectif du projet est de créer une interface web permettant de présenter une entreprise de manière simple, moderne et structurée.

## 🛠️ Technologies utilisées

* **HTML5** — structure des pages
* **CSS3** — mise en forme et design
* **Git** — gestion des versions
* **GitHub** — hébergement du code source

## 📂 Structure du projet

```text
projet BAS/
│
├── index.html
├── style.css
├── README.md
│
└── img/
    ├── arrière plan.jpg
    └── menuisier.webp
```

## 🎯 Objectifs du projet

Ce projet m'a permis de travailler notamment sur :

* La structuration d'une page avec HTML5
* La mise en forme avec CSS3
* L'utilisation des images dans une page web
* La création d'une interface organisée et responsive
* L'utilisation de Git et GitHub pour gérer et partager un projet

## 🚀 Installation

Pour utiliser le projet localement :

1. Cloner le dépôt :

```bash
git clone https://github.com/Brahimi-03/entreprise-BAS.git
```

2. Ouvrir le dossier du projet.

3. Ouvrir le fichier `index.html` dans un navigateur.
